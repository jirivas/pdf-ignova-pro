# Contributing

Contributions are welcome after the source repository is public.

## Basic process

1. Create an issue or discussion for non-trivial changes.
2. Work in a branch.
3. Submit a pull request.
4. Do not commit secrets, private certificates, customer data, or proprietary code.
5. Ensure all new dependencies use licenses compatible with the project license and SignPath Foundation requirements.
6. Changes from non-committers require review before merge.

## Release-sensitive files

Changes to build scripts, GitHub Actions, installer configuration, dependency manifests, or SignPath configuration require special review because they affect release provenance.
