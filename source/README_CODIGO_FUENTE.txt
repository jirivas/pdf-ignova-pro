PDF IGNOVA PRO 1.9.12 — CÓDIGO FUENTE DISTRIBUIDO

Este paquete contiene el código JavaScript y los recursos ejecutados por la
aplicación Electron PDF Ignova Pro 1.9.12.

NOVEDADES DE ESTA VERSIÓN
La interfaz incorpora español, inglés, portugués, alemán, francés, chino
simplificado y malayo, elegibles desde el selector superior con banderas. La
selección se conserva entre usos.
La impresión permite generar y enviar documentos en tamaño original, A4, A3,
A2 y A1, con orientación automática y contenido centrado sin deformación.
También se incorpora OCR de una zona rectangular y la creación de un PDF A4
en blanco para construir documentos pegando, añadiendo o copiando páginas.
La versión 1.9.5 corrigió la conversión del flujo WinRT que impedía ejecutar el
OCR en Windows y añadió una prueba funcional de reconocimiento. La versión
1.9.6 mueve OCR ventana a la barra superior para que permanezca visible, incluso
cuando la barra de edición no cabe completa. La distribución oficial incluye un
instalador con accesos directos y desinstalación, además del ZIP portátil.
La versión 1.9.7 reconoce enlaces web y direcciones de correo, incluidas las
anotaciones internas del PDF, y ofrece elegir entre abrir el destino o editar el
texto. Solo permite abrir destinos HTTP, HTTPS y mailto.
La versión 1.9.8 permite seleccionar fragmentos largos de texto nativo, copiarlos
con el botón derecho, desde el menú Editar o con Ctrl+C/Comando+C, y amplía el
zoom hasta el 500 % mediante niveles progresivos.
Esa misma versión incorpora una distribución universal para macOS 12 o posterior,
compatible con Apple Silicon e Intel. En Mac, el OCR local utiliza Vision, los
TIFF de varias páginas se procesan con ImageIO y los documentos pueden abrirse
desde Finder. Los archivos de Office requieren LibreOffice en macOS y DWG/DXF
continúa siendo una conversión exclusiva de Windows con AutoCAD.
La versión 1.9.9 añadió la vista general horizontal de todas las páginas, salto
directo mediante el número de página, resaltado que conserva el contraste,
tapado de color unificado, texto multilínea estable, guardado nativo seguro y
un organizador de dos paneles para arrastrar páginas entre documentos.
La versión 1.9.10 abre «Guardar como» directamente en el selector nativo unido
a la ventana activa, impide aperturas duplicadas y protege el archivo anterior
hasta completar la sustitución. «Tapado» deja la barra superior y pasa al nuevo
menú Dibujo, donde conserva el selector de color.
La versión 1.9.12 hace que la edición de texto nativo sustituya visualmente al
texto original desde el primer momento, sin mostrar una copia superpuesta.
Añade un panel Páginas con una cuadrícula de miniaturas, reordenación por
arrastre y apertura con doble clic, y un panel Unir archivos que admite selección
o arrastre de varios PDF para formar un único documento cuyas páginas pueden
revisarse y reordenarse antes de guardar.

LICENCIA DEL CÓDIGO PROPIO
El código propio se distribuye bajo GNU GPL versión 3 o posterior
(GPL-3.0-or-later). Los componentes de terceros conservan sus licencias.

MODELO DE APOYO
La aplicación funciona completa desde el primer día. Durante los primeros
30 días no muestra avisos. Después presenta, como máximo una vez cada 30 días,
un recordatorio discreto para adquirir una licencia permanente por equipo.
La licencia elimina el recordatorio y apoya el desarrollo de la compilación
oficial; no es una condición para ejercer los derechos concedidos por la GPL.

MARCA
La GPL cubre el código, pero no concede derechos sobre el nombre PDF Ignova
Pro, los logotipos ni otros signos distintivos. Una versión modificada no debe
presentarse como distribución oficial de IGNOVA sin autorización.

FUENTE DISPONIBLE
El árbol de desarrollo original de React no se conservó en el instalador de
partida. Este paquete ofrece el JavaScript ejecutable recuperado, legible y
modificable, junto con los recursos y scripts de escritorio. Conviene conservar
en adelante el repositorio de desarrollo anterior al empaquetado.
