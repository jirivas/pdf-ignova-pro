INSTALACIÓN DE PRUEBA

Cómo probarla.

1. Descargar

Descarga el ZIP de Windows x64 desde el botón superior.

2. Extraer

Extrae el contenido completo del ZIP en una carpeta. No ejecutes el programa directamente desde dentro del ZIP.

3. Ejecutar

Abre PDF Ignova Pro.exe. Si Windows muestra un aviso por falta de firma, recuerda que esta compilación es exclusivamente de prueba.

CHECKLIST

Pruebas mínimas.

Abre al menos tres PDF diferentes: uno pequeño, uno escaneado y uno grande. Comprueba navegación, búsqueda, edición, guardado, impresión y el comportamiento del programa después de varias operaciones seguidas.

Si encuentras un problema, indica qué estabas haciendo, qué esperabas que ocurriera y qué ocurrió realmente. Si puedes reproducirlo, indícalo también.
