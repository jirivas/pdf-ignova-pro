INSTALACIÓN DE PRUEBA

Cómo probarla.

1. Descargar

Descarga el instalador de Windows x64 desde el botón superior.

2. Instalar

Ejecuta el Setup.exe y elige la carpeta y los accesos directos.

3. Probar o desinstalar

Abre PDF Ignova Pro. Puedes retirarlo después desde Configuración > Aplicaciones.

CHECKLIST

Pruebas mínimas.

Abre al menos tres PDF diferentes: uno pequeño, uno escaneado y uno grande. Comprueba navegación, búsqueda, edición, enlaces web y correos, guardado, impresión y el comportamiento del programa después de varias operaciones seguidas.

Si encuentras un problema, indica qué estabas haciendo, qué esperabas que ocurriera y qué ocurrió realmente. Si puedes reproducirlo, indícalo también.
