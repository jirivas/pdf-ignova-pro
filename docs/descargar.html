Descargar PDF Ignova Pro.

La versión 1.9.12 incorpora un panel Páginas con cuadrícula de miniaturas y otro panel para unir varios archivos en un único PDF. Al editar texto, el original se sustituye sin crear una imagen duplicada. Puede descargarse y utilizarse gratuitamente.

Instalador para Windows Instalador universal para Mac

Windows 10/11 x64 · macOS 12+ Intel/Apple Silicon · Código abierto GPL · Descarga gratuita

Importante: Windows puede mostrar SmartScreen. En Mac, abre el DMG, arrastra PDF Ignova Pro a Aplicaciones y, si Gatekeeper avisa, pulsa con el botón derecho sobre la aplicación y elige Abrir. El DMG aún no está notarizado por Apple.

ANTES DE EJECUTAR

Elige tu sistema.

  • Descarga y ejecuta el instalador Setup.exe
  • El instalador crea los accesos directos
  • Puedes desinstalarlo desde Configuración > Aplicaciones
  • En Mac, arrastra la app a Aplicaciones
  • Para desinstalar en Mac, muévela a la Papelera
  • Elige el idioma desde las banderas de la barra superior
