## Project description

PDF Ignova Pro is an Open Source Windows desktop application for day-to-day PDF document work. It provides a simple professional interface for viewing, organizing, editing and processing PDF files, including page operations, annotations, document-wide search, printing, watermarks, conversion workflows and related PDF utilities.

The project is maintained in a public GitHub repository. Official Windows binaries are built by GitHub Actions on GitHub-hosted Windows runners from the committed public source package and build configuration.

## Why code signing is requested

We would like to use SignPath Foundation code signing so users can verify the provenance and integrity of official Windows releases and distinguish them from modified or unofficial builds.

Our objective is to ensure that published PDF Ignova Pro Windows binaries are verifiably produced by the public repository build workflow from the corresponding source revision and are not modified after the trusted build.

## Build and release process

- Source repository: public GitHub repository.
- Build system: GitHub Actions.
- Build agents: GitHub-hosted Windows runners.
- Source release: PDF Ignova Pro 1.9.2 GPL source package committed to the repository.
- Dependency installation: `npm ci` using the committed lock file.
- Automated tests: syntax, support-reminder, document-wide search and search-navigation smoke tests.
- Packaging: Electron Windows x64 package generated by the repository workflow.
- Public release: `v1.9.2`, including the unsigned Windows x64 build artifact generated by GitHub Actions.
- Signing requests: after onboarding, submitted only by the official GitHub Actions workflow.
- Approval: manual approval by the designated project approver as required by SignPath Foundation.
- Verification: signed artifacts are checked before publication as official releases.

## Privacy

PDF Ignova Pro is intended to process PDF documents locally.

The project privacy policy is published in `PRIVACY.md`. The application does not transmit user documents simply by opening or editing them. Any network-enabled function must be explicitly user initiated and documented before release.

## Support reminder

PDF Ignova Pro remains fully functional without a support license. The first 30 days contain no reminder. Afterwards the official build may display a discreet reminder at most once every 30 days. A support license suppresses that reminder and supports development of the official distribution; it does not limit or replace the rights granted by the GPL.

## Third-party components

Third-party Open Source components are documented in `THIRD_PARTY_NOTICES.md` and retain their respective licenses. Proprietary project code is not intended to be included in the SignPath Foundation signing scope.
