FUNCIONES

Las herramientas PDF que se usan de verdad.

Ver y organizar

Apertura de documentos, panel de páginas, reordenación, duplicado, eliminación, giro e inserción.

Editar y anotar

Herramientas de texto, cuadros de texto, resaltado, tachado y anotaciones para revisión de documentos.

Buscar en todo el PDF

Búsqueda en todas las páginas con navegación entre coincidencias anterior/siguiente.

Imprimir y exportar

Flujos de impresión y conversión orientados al trabajo diario con documentación técnica y administrativa.

Marca de agua

Aplicación de marcas de agua sobre páginas seleccionadas con controles de posición y presentación.

OCR y conversiones

Flujos OCR y conversiones cuando están soportados por los componentes open source incluidos.

FILOSOFÍA

Software abierto, distribución oficial y apoyo voluntario.

El código propio de PDF Ignova Pro se distribuye bajo GNU GPL v3 o posterior. La marca IGNOVA identifica las compilaciones oficiales. El programa permanece funcional aunque el usuario no active una licencia de apoyo.

Los primeros 30 días no se muestra ningún recordatorio. Después puede aparecer un aviso discreto como máximo una vez cada 30 días.

Privacidad por defecto

La aplicación está diseñada para trabajar localmente con tus documentos. Cualquier función futura que necesite red deberá ser iniciada por el usuario y documentada previamente.
